OPENHOOPVISION

OpenHoopVision 是一个免费开源的 AI 篮球视频分析项目,核心目标很明确:把一段普通的业余或青少年篮球比赛录像,自动转换成可复盘、可追踪的结构化数据,让没有专业数据分析团队的教练和球员也能获得量化洞察。

01

从视频到两种产物

输入一段比赛视频,OpenHoopVision 会逐帧分析,最终输出两样东西:

标注视频H.264

在画面上实时叠加球员标签、队伍颜色、事件状态、比分板和球场小地图,直观呈现分析结果。

结构化数据JSONL

逐帧记录所有原始检测结果和推断出的事件,供后续计算和自定义分析。

检测与跟踪

识别球员、篮球、篮筐、裁判等对象,并在帧间维持稳定的局部轨迹。

身份与队伍

结合外观 ReID(重识别)、球衣号码 OCR 和队伍颜色,在球员移动或遮挡时持续锁定身份,并区分对阵双方。

球场映射

检测球场关键点,将球员位置映射到标准球场坐标系,并绘制小地图(Mini-map)展示战术跑位。

事件推断

自动识别投篮、运球、传球、篮板、失误和抢断六类事件;投篮结果细分为 made(命中)、miss(未中)或 unknown(不确定)。

02

可扩展的分析流水线

分析流程被设计成清晰的阶段,便于理解和二次开发:

01

检测与姿态

用模型找出球场上的实体并估计关键点。

02

局部跟踪

在帧与帧之间保持球员和球的轨迹稳定。

03

身份与队伍

跨时间匹配球员,分类队伍,并读取球衣号码。

04

事件推断

跟踪球的动作和球权变化,处理事件重叠(投篮优先于重叠的传球),并更新比分。

05

输出

渲染标注视频并写入逐帧 JSONL,确保视觉呈现与底层数据严格对齐。

03

性能指标(作者基准)

以下数据来自项目作者在 README 中公布的评估结果,基于其自行整理和标注的数据集,并非第三方独立复现。

任务模块关键指标
篮球对象检测(RF-DETR)mAP@0.5: 84.9%
球场姿态估计(YOLO26s)mAP@0.5: 96.8%
端到端投篮事件Precision: 85.51%,Recall: 83.10%,F1: 84.29%

注意:这些指标对应不同的任务(检测、关键点、事件识别),不能简单概括为“系统整体准确率”。端到端投篮评估仅覆盖 7 段视频、71 次投篮,尚未经过复杂比赛场景的大规模验证。

04

安装与运行

① 基础环境

需要 Python 3.10 或更高版本。

# 检查 Python 版本
python --version # >= 3.10

② 视频输出依赖

需要安装 FFmpeg,并确保 ffmpeg 命令可在终端中调用,用于生成 H.264 格式的标注视频。

# 检查 FFmpeg 是否可用
ffmpeg -version

💎 核心价值

  • 降低门槛:让业余教练、球员家庭或篮球爱好者,以零成本从录像中提取可用于复盘和战术讨论的量化数据。
  • 可扩展框架:整个流水线支持添加新的事件类型和分析应用。

当前局限

  • 功能边界:暂不支持助攻、盖帽和犯规的自动识别;自动精彩片段剪辑功能尚在规划中。
  • 精度依赖:分析效果高度依赖视频质量,复杂遮挡、低分辨率或非标准机位会影响检测和跟踪的稳定性。
  • 工程成熟度:项目版本较新(v0.1.0),实际复杂比赛中的鲁棒性仍需更多验证。
